# Agent Note：时间上下文星期名

状态：已实现

[English](2026-10-01-time-context-weekday.md) | 中文

## 问题

Beardy 家庭 agent 在 2026-09-30（星期三）的一份摘要中写下了 "Tue Sep 30"。它唯一的时钟是 `dsh-time-context`，其读数给出形如 ISO 的时间戳，例如 `2026-09-30T20:30:00-07:00[America/Phoenix]`，但不含星期名，因此模型只能根据日期自行推算星期，结果推算错误。

## 决策

`dsh-time-context` 接受可选的 `weekday` Config 字段，默认 `false`。设为 `true` 时，读数中的时间戳后会附上其本地日期的英文星期名，形如 `2026-09-30T20:30:00-07:00[America/Phoenix] (Wednesday)`。星期名取自格式化时间戳所用的同一组 `Intl.DateTimeFormat` 部件与时区，因此不会与显示的日期不一致。不变式配套模块同时接受带与不带该后缀的读数，因为已发布的会话中没有该后缀；若后缀中的星期名与时间戳本地日期不符，则予以拒绝。Beardy 组合包启用该字段；Web 组合包保持默认值。

## 备选方案

- **始终渲染星期名** — 已否决，因为这会改变未要求此功能的部署中的每条现有读数、已录制快照与模型请求。
- **渲染完整日期短语，例如 `Wednesday, September 30`** — 已否决，因为 ISO 时间戳已无歧义地携带日期；只有星期名需要模型进行日历推算。

## 影响

Beardy 的每次注入读数多出一个单词。默认部署的读数逐字节保持不变。不含星期名的已发布会话可继续重放，任何带星期名的读数都会与其自身的本地日期进行核对。
