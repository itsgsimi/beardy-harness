# Agent Note: 选择器显示位置独立于 preset 可用性

Status: implemented

[English](2026-09-09-compact-mode-picker.md) | 中文

## 问题

新建会话选择器混合了通用 Agent、专用组装，以及面向无人值守或 Discord 运行的 preset。完整描述使每个新增模式都会增加菜单高度。如果为了缩短菜单而从发现结果中移除 preset，也会移除集成和会话恢复所依赖的组装。

## 决策

Preset 展示元数据发布可选的 `picker` 显示位置：`main`、`more` 或 `hidden`。`agent-presets` 设置命名空间按 id 保存覆盖该元数据的用户偏好。远程名单保持完整，并投影解析后的显示位置；未指定显示位置时，自定义 preset 保持可见。[Preset 包](../../../../packages/preset/agent-presets/README.zh.md) 独立于[会话组装](../architecture/2026-08-03-per-session-agent-presets.zh.md)拥有这些展示默认值。

[Web 选择器](../../../../packages/client/ui-agent-preset/README.zh.md) 渲染主列表和一个可折叠的「更多模式」分组，并为随附模式显示简短的本地化描述。即使当前模式被隐藏或分组，选择器也会将其置于主列表。管理模式通过现有宿主设置写入器更改显示位置；保存被拒绝时显示错误，不改变已显示的偏好。隐藏的 preset 保留正常的发现、直接选择和会话标签行为。

[复制的 preset](../simplification/2026-08-08-copy-only-preset-authoring.zh.md) 不继承源 preset 的排序和选择器显示位置，因此没有自身已保存覆盖值的副本会出现在主列表中。设置页面保留损坏的 preset 以便修复；选择器及其显示位置对话框使用健康名单。

## 考虑过的替代方案

**将所有行保留在滚动列表中。** 滚动可以限制菜单高度，但低频模式和集成专用选项仍与常用模式混杂。紧凑的主列表为日常选项提供稳定位置。

**从名单中移除隐藏的 preset。** 发现结果也服务于集成选择、恢复和可读的会话标签。选择器可见性不能决定这些使用方能否解析 preset。

**在浏览器中硬编码分组。** 仅存在于客户端的 id 列表无法表达部署或自定义 preset 的意图。元数据提供部署默认值，设置则允许用户无需编辑已安装文件就能选择显示位置。

## 影响

选择器显示位置属于展示数据，不增加会话事件，也不改变会话格式。管理功能仍可访问完整名单，当前模式即使通常隐藏也保留可见入口。新发现的自定义模式保持可见，因此拥有大量自定义模式的用户需要主动将其分组或隐藏。

针对性的宿主测试覆盖元数据、已保存覆盖值、复制的 preset 和隐藏模式的直接选择。客户端测试覆盖分组、保存被拒绝和过时的名单响应。无需密钥的 Web 场景记录折叠及展开菜单，并通过完整应用验证持久保存、恢复和当前隐藏模式的选择。
